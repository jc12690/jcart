# Jarredmcarter.com

Personal site for Jarred Carter: security engineer, Pilates instructor.
Static HTML/CSS/JS, generated by a small Python script, hosted on GitHub Pages.

## Editing

**Never edit `index.html` directly** — it is generated and will be overwritten.
Everything you can change lives in `content/site.json`:

```bash
python3 tools/build.py        # content/site.json -> index.html
python3 -m http.server 8900   # preview at http://localhost:8900
```

A pre-commit hook rebuilds `index.html` automatically, so a content edit can't
be committed without the page catching up. Git hook settings are per-clone and
are not committed, so if you ever clone this repo somewhere new, turn it back on:

    git config core.hooksPath .githooks

**See [EDITING.md](EDITING.md) for the full guide** — adding projects, adding
photos, publishing the IEEE/NASA/CNCF entries, and going live with the Pilates site.

```

content/site.json   every word, link, and image choice
content/htb.json    the Hack The Box log: machines and modules (EDITING.md, Recipe 9)
assets/css          site.css (styling) + cursors.css (generated)
assets/css/cursors.css  generated pixel cursors
assets/js/site.js   theme switch, hero animation, router, lightbox, command palette
assets/img          .png = 1-bit dither, .jpg = colour (always in pairs)
tools/build.py      the generator
tools/dither.py     photo -> the dither/colour pair
tools/modeling_media.py  photo or clip -> the modeling page's web copies
tools/icons.py      favicon.svg, favicon.ico, apple-touch-icon.png
tools/share_cards.py  the link-preview pictures (assets/share.jpg, quickbio/share.jpg)
404.html            the System 7 bomb page for addresses that don't exist
.well-known/security.txt  how to report a security problem; renew its Expires yearly
_config.yml         publishes .well-known/ and keeps EDITING.md, README.md, content/, and tools/ off the live site
sitemap.xml         pages for search engines (modeling and dot-quickbio left out on purpose); robots.txt points to it
tools/cursors.py    the pixel cursors
media/              original photo library
files/              résumé and PDFs
experience/ projects/   redirect stubs, old URLs -> new #/slug routes
fitness/            the fitness site: playlists and Mega Move Monday live in fitness/weekly.js
quickbio/           the Instagram link-in-bio page
modeling/           the modeling page, linked only from quickbio (EDITING.md, Recipe 10)
dot-quickbio/       the page the Dot card and band open; unlisted (EDITING.md, Recipe 12)
privacy.html        redirect to the Retrac Labs privacy policy on retraclabs.co
```

## Notes

- `CNAME` points the repo at jarredmcarter.com. Don't delete it.
- The SSH key `jc12690` sits in this folder and is gitignored. Keep it that way.
- Analytics is Cloudflare Web Analytics, cookieless, so the site has no consent
  banner. Token lives in `content/site.json` under `site.analytics_token`.
- Dark is the default theme; light is opt-in via the menu-bar THEME switch and
  is stored in `localStorage` as `jc-theme`. See EDITING.md for the token rules.
